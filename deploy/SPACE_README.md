# باحث V2

تجربة عامة للبحث الدلالي العربي في مجموعة نصوص تعليمية مضمّنة، بهوية بصرية سعودية.
يمكنك تجربة السؤال نفسه عبر ستة أحجام من متجهات Matryoshka، ومراجعة المقاطع ومصادرها.

النسخة العامة لا تستقبل ملفات شخصية. يدعم المشروع المحلي رفع PDF النصي وTXT وMarkdown.
قد تُحفظ الاستعلامات مؤقتًا في ذاكرة الخدمة لتسريع تكرار البحث؛ لا تُدخل بيانات شخصية.
درجات التشابه ليست نسب ثقة، والمقاطع المرتبة قد لا تحتوي جوابًا عن السؤال.
