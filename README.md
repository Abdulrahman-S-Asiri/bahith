# باحث | Bahith

**بحث في المستندات العربية، بهوية سعودية ونتائج تقود إلى مصادرها.**

باحث تطبيق محلي للبحث العام في ملفات PDF النصية وTXT وMarkdown. يستخدم نموذج
**Harrier-Arabic-Matryoshka-0.6B**، ويتيح قياس أثر اختصار المتجهات على جودة الاسترجاع.
الواجهة عربية من اليمين إلى اليسار، بألوان الرمل والنخيل ولمسات هندسية مستوحاة من التراث.

![واجهة باحث](docs/screenshot.png)

## الموجود في هذه النسخة

- رفع المستندات وحفظ أصل الملف ومقاطعه محليًا في SQLite.
- منع الملفات المتطابقة، واستبدال النسخ وحذف المستندات ومقاطعها وتقييماتها.
- ربط كل نتيجة بالمستند ورقم صفحة PDF وسياق المقطع.
- بحث دلالي، وبحث بالكلمات (BM25)، ودمج الترتيبين (RRF)، وبحث متدرج.
- أبعاد Matryoshka الستة: **64، 128، 256، 512، 768، 1024**. الافتراضي 1024.
- حفظ تمثيلات النصوص على القرص؛ لا يعاد ترميز النصوص غير المتغيرة عند إضافة مستند.
- ذاكرة مؤقتة محدودة للاستعلامات؛ تغيير الأبعاد للسؤال نفسه يعيد استخدام المتجه.
- اختبارات رياضية ووظيفية دون تنزيل النموذج، وأداة تقييم حقيقية تنتج دليلًا بصيغة JSON.
- واجهة تعمل بالنماذج العادية دون JavaScript؛ التحسين التفاعلي محلي ولا يحتاج CDN.

المجموعة المضمّنة ذات 30 نصًا **مجموعة تعليمية تجريبية**، وتُميَّز عن ملفات المستخدم.
المنتج عام؛ الثقافة السعودية هي الهوية البصرية وليست قيدًا على موضوع المستندات.

## التجربة العامة V2

يتوفر وضع منفصل للنشر للعامة، يبحث في النصوص المضمّنة فقط. يستخدم مكتبة مؤقتة نظيفة،
ويرفض رفع الملفات وتغييرها وتقييماتها قبل قراءة أجسام الطلبات. المكتبة المحلية تبقى
للاستخدام الشخصي. يوجد حد لبحث متزامن واحد واستجابة واضحة عند الانشغال، وفحص جاهزية
للنموذج والفهرس. هذه ضوابط لتجربة عامة محدودة وليست خدمة لإدارة ملفات عدة مستخدمين.

راجع [دليل النشر](deploy/README.md) وملفات Docker. يلزم حساب استضافة وخادم قادر على تشغيل
Python وPyTorch؛ رابط GitHub وحده لا يشغّل النموذج. لا نعلن رابط تجربة حية قبل التحقق منه.

## تشغيل سريع — Windows

تحتاج Python **3.11**؛ هذا هو الإصدار المستهدف والمختبر حاليًا.

```powershell
git clone https://github.com/Abdulrahman-S-Asiri/bahith.git
cd bahith
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.ps1
```

افتح <http://127.0.0.1:8000>. إذا منعت سياسة PowerShell تشغيل الملف، استخدم مباشرة:

```powershell
$env:OMP_NUM_THREADS = '4'
$env:MKL_NUM_THREADS = '4'
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000 --no-access-log
```

المشغّل يحدّ توازي المعالج إلى أربع وحدات ما لم تضبطه بنفسك. في تجربة المتصفح المحلية
أزال هذا بطئًا شديدًا عند أول بحث داخل عامل الويب؛ هو إعداد ابتدائي قابل للقياس والتعديل،
وليس ضمان سرعة على كل جهاز. تهيئة النموذج والفهرس أبطأ من البحث بعد تخزينهما.

على Linux/macOS:

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8000 --no-access-log
```

`requirements.txt` يثبّت الإصدارات المباشرة والمتعدية المستخدمة في التحقق.
`requirements.in` يشرح الاعتماديات المباشرة. التشغيل المحلي جرى على Windows؛ CI يستهدف Linux.

## استخدام المستندات

1. افتح «الوثائق» وارفع PDF نصيًا أو ملف TXT/Markdown بترميز UTF-8.
2. راجع نتيجة الاستخراج وأي تحذير بشأن صفحات لم يُستخرج نصها.
3. ابحث من الصفحة الرئيسية أو قيّد البحث بمستند معين.
4. افتح المقطع لمراجعة سياقه، أو افتح الملف الأصلي.
5. استخدم «إدارة» لاستبدال ملف أو حذفه، و«هل أفادتك؟» لحفظ تقييم محلي.

حدود الاستيراد: **10 ميجابايت، 300 صفحة PDF، 500 ألف حرف مستخرج لكل ملف**.
لا تعبر المقاطع حدود الصفحات. تقسيم النصوص الحالي يعتمد على حدود الفقرات والجمل والكلمات
بحد 1000 حرف وتداخل محدود؛ هو خط أساس قابل للقياس، لا ادعاء بأنه أفضل تقسيم لكل مستند.
في TXT/Markdown، الصفحة 1 مرجع منطقي للملف وليست ترقيم طباعة.

عند أول بحث دلالي يُحمَّل النموذج وتُجهَّز التمثيلات. البحث بالكلمات لا يحتاج تشغيله.
يلزم الإنترنت لتنزيل النموذج أول مرة؛ يمكن التشغيل محليًا بعد ذلك:

```powershell
$env:HF_HUB_OFFLINE = '1'
.\start.ps1
```

إذا كان النموذج غير متاح، يبقى تصفح المستندات والبحث بالكلمات متاحين، وتظهر رسالة مفهومة
عند تعذر البحث الدلالي. لا توجد مفاتيح API مطلوبة.

## Matryoshka: ما الذي نثبته؟

النموذج مثبت على النسخة:

```text
Omartificial-Intelligence-Space/Harrier-Arabic-Matryoshka-0.6B
397a969cf4db4b9bcda254e857823d87077b7e6f
```

نأخذ أول `d` إحداثيات من المتجه، ثم نعيد تطبيع متجهات السؤال والمقاطع قبل حساب cosine.
الأبعاد المستخدمة مطابقة لسلم التدريب المعلن في بطاقة النموذج. نرفض الأبعاد غير الصالحة
والمتجهات ذات القيم غير المحدودة أو الطول الصفري، ونحافظ على ترتيب تعادل ثابت.

اختصار الأبعاد يقلل تكلفة **المتجهات والبحث فيها**؛ لا يقلل تلقائيًا حجم النموذج أو وقت توليده
للمتجه. التطبيق يحتفظ بالتمثيل الكامل لتغيير الأبعاد وإعادة الترتيب، لذلك لا ندعي أن اختيار
64 بُعدًا يخفض ذاكرة العملية كلها. مخطط المتجه وصف عددي وليس تفسيرًا لغويًا لمعناه.

في البحث المتدرج، يختار البُعد المحدد حتى 50 مرشحًا ثم يعاد ترتيبهم بـ1024 بُعدًا. لا يمكن
للمرحلة الثانية استعادة مقطع لم يدخل قائمة المرشحين. على المجموعة الصغيرة، قد تضم القائمة
كل المقاطع، وعندها لا يثبت الاختبار أي تسريع من الترشيح.

## الاختبار والتقييم

في القياس المحلي بتاريخ 2026-09-07 على 120 استعلامًا و30 نصًا تجريبيًا، حقق البحث
الدلالي بـ1024 بُعدًا **P@1 = 90.0%** و**MRR@5 = 0.9281** و**Success@5 = 96.7%**.
حافظ التنفيذ على خط الأساس المقاس محليًا؛ هذه نتائج كشف تراجع وليست دقة عامة على
المستندات العربية. المقارنة المدمجة لم تحسن النتيجة، لذا بقي البحث الدلالي الافتراضي.
راجع [التقرير وملفات الأدلة](docs/benchmarks/README.md) للأبعاد الستة والقيود وإعادة التشغيل.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
.\.venv\Scripts\python.exe evaluate.py --output evaluation-results/regression.json --dimensions 64,128,256,512,768,1024 --methods semantic --repeats 5
```

الأمر الأول لا يحتاج النموذج الحقيقي. الثاني يشغله ويكتب المقاييس والنتائج لكل سؤال،
مع بصمات البيانات وإصدارات التشغيل وإعداداته. راجع [بروتوكول التقييم](docs/EVALUATION.md)
لإضافة أسئلة خارجية وفصل بيانات التطوير والمعايرة والاختبار.

**معيارنا هو النتيجة القابلة للتحقق.** مجموعة الـ120 سؤالًا القديمة اختبار تراجع داخلي
على 30 نصًا، وليست اختبارًا مستقلاً لجودة البحث في العربية عمومًا. الملفات الجديدة داخل
`tests/fixtures` أمثلة مصطنعة وغير مراجعة بشريًا، ولا نقدّمها كدليل إنتاجي.

توجد قياسات جودة وترتيب واستدعاء، ومقارنات عبر الأبعاد وفواصل bootstrap مع حدودها.
حالات «لا إجابة» منفصلة. لا توجد حاليًا عتبة امتناع معايرة على بيانات مراجعة بشريًا؛
البحث الدلالي يعرض أقرب النتائج وقد لا تحتوي إجابة. درجات التشابه **ليست نسب ثقة**.

## البيانات والخصوصية

- تحفظ الملفات الأصلية والمقاطع والتقييمات في `.bahith/library.sqlite3`.
- تحفظ التمثيلات في `.bahith/embeddings/`، والاستعلامات المؤقتة في الذاكرة فقط.
- إرسال تقييم يحفظ نص السؤال محليًا مع المقطع وطريقة البحث؛ لا يُرسل إلى خدمة خارجية.
- `.bahith/` مستثناة من Git. لا ترفع ملفاتك الخاصة أو تقارير تقييمها إلى المستودع.
- عند حذف مستند أو استبداله، يمسح التطبيق الملفات المشتقة قبل تغيير الأصل، ويسقط فهرس
  الذاكرة فورًا. إذا تعذر المسح، يبقى المستند الأصلي دون تغيير لتتمكن من إعادة المحاولة.
- لا يوجد حساب مستخدم أو عزل بين مستخدمين. شغّل **عملية واحدة** على `127.0.0.1` للاستخدام
  الشخصي؛ هذه النسخة غير مهيأة للنشر العام أو الوصول المشترك.
- الطلبات المعدِّلة محمية برمز CSRF وفحص المصدر واسم المضيف. الملفات تُعرض بأنواع محتوى
  محددة، والنصوص تُهرب في القوالب. التشغيل المقترح يعطل سجل روابط البحث.

يمكن تغيير موقع المكتبة قبل التشغيل عبر `BAHITH_DATA_DIR`؛ احتفظ بنسخة احتياطية من المجلد
والتطبيق متوقف. هذا إعداد محلي، ولا يغير مستندات Git الأصلية.

## ما لم نثبته بعد

- جودة مستقلة على مجموعة كبيرة ومتنوعة ومراجعة بشريًا.
- التعامل مع جميع تخطيطات PDF العربية، أو OCR، أو الجداول والصور.
- تفوق البحث المدمج أو المتدرج في كل مجال؛ كلاهما خيار تجريبي إلى أن تثبت المقارنة فائدته.
- صلاحية تشغيل متعدد المستخدمين أو إنتاج عام.

لا يشمل الإصدار توليد إجابات، أو تدريب نموذج جديد، أو تنفيذ معاملات مالية.
الخطوة التالية هي جمع أسئلة ومقاطع مرجعية من مستندات فعلية، ومراجعتها ثم تجميد اختبار مستقل.

## English

Bahith is a local Arabic document-search application with a Saudi-inspired interface. Import
text PDFs, UTF-8 text or Markdown; search with pinned Matryoshka embeddings, BM25, reciprocal-rank
fusion, or a shortlist/full-vector cascade; inspect source passages and PDF pages.

The default is full 1024-dimensional semantic retrieval. Document embeddings persist per unique
text and model revision, and a bounded in-memory query cache avoids re-encoding on dimension
changes. Source files and feedback stay in an ignored local SQLite library. No API key is needed.

Use Python 3.11, install `requirements.txt`, and run `uvicorn app:app --host 127.0.0.1 --port 8000
--no-access-log`. Run `python -m unittest discover -v` for model-free tests. See
[evaluation documentation](docs/EVALUATION.md) for reproducible JSON evidence. The built-in
120-query/30-passage suite is regression-only; synthetic fixtures are explicitly unreviewed.
There is no calibrated abstention policy or claim of production-wide Arabic accuracy.
